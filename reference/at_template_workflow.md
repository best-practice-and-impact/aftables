# Insert full 'aftables' template workflow

Insert at the cursor (a) demo templates for cover, contents and notes
tables, and (b) a call to
[`create_aftable`](https://best-practice-and-impact.github.io/aftables/reference/create_aftable.md)
pre-filled with demo data.

## Usage

``` r
at_template_workflow()
```

## Value

Empty list. Function is used for side effect.
