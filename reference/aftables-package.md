# aftables: Create Spreadsheet Publications Following Best Practice

Generate spreadsheet publications that follow best practice guidance
from the UK government's Analysis Function, available at
<https://analysisfunction.civilservice.gov.uk/policy-store/releasing-statistics-in-spreadsheets/>,
with a focus on accessibility. See also the 'Python' package 'gptables'.
