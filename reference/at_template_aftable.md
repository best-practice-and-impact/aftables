# Insert 'create_aftable' template

Insert at the cursor a template for
[`create_aftable`](https://best-practice-and-impact.github.io/aftables/reference/create_aftable.md)
from the 'aftables' package, pre-filled with demo data.

## Usage

``` r
at_template_aftable()
```

## Value

Empty list. Function is used for side effect.
