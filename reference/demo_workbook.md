# A Demo 'Workbook' Object

A pre-created 'openxlsx2' wbWorkbook-class object generated from an
aftables-class object with
[`generate_workbook`](https://best-practice-and-impact.github.io/aftables/reference/generate_workbook.md).

## Usage

``` r
demo_workbook
```

## Format

An 'openxlsx2' wbWorkbook-class object with 5 sheets.
